# brittanyperera.com

A playable late-90s Mac OS desktop that doubles as Brittany Perera's portfolio.

## Run

```
pnpm install
pnpm dev
```

## Gates

Run each and check its exit code before committing:

```
pnpm typecheck
pnpm lint
pnpm test
pnpm e2e
```

All user-visible text lives in `src/content/`.
